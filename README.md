# Geodata

Simple service for getting list of cities, countries and states all around the world
You can either deploy it as a simple node service or use the dockerfile especially if you have issues with node version or mainly sqlite3 as all data is stored locally.
More routes will be added furthermore.

### Project setup

```
npm install
```

### Start the project

In the project directory, run the following command:

```
npm start
```

### Run in development mode

```
npm run dev
```

Please check <b>package.json</b> for additional information.
